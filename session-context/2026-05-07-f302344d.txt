Turn 44 [ASSISTANT]:
**Jina Reader** (`r.jina.ai`) is a free service — you just prefix any URL with `https://r.jina.ai/` and it returns the page as clean markdown. No API key, no cost, dead simple. That's why it's here.

**Is it the best option?** It's the best *free* option. The real alternatives:

| Option | Pros | Cons |
|---|---|---|
| **Jina Reader** (current) | Free, zero setup | Fails on JS-heavy SPAs, blocked by some sites |
| **Firecrawl** | Handles JS, structured output, reliable | Paid (~$16/mo+) |
| **Google Places** (already using) | Structured data, reviews, hours, photos | Only works for businesses with a Maps listing |
| **Direct fetch + parse** | Free, fast | Only works on simple static sites |
| **OpenAI web search** | No scraping, just ask GPT to look it up | Costs tokens per lookup, less control |

**For this use case (local vendors/artists/organizers):**
- Google Places already covers physical businesses well — that's your best signal
- Jina is fine as a fallback for websites
- Instagram enrichment has no good free option — Instagram blocks all scrapers; you'd need something like Apify ($) for that

**Recommendation:** Keep the current stack (Jina + Google Places) — it's good enough for v1. The bigger ROI is fixing the gap where vendors only give an IG handle and enrichment never fires. Want me to update the system prompt to push harder for a website or Google Maps link when only an IG is given?
